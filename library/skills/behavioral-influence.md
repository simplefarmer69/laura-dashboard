# Behavioral influence (honest persuasion)

The model lives in `library/95-behavioral-science.md`. This is the procedure.

## Before writing

1. Name the ONE behavior you want: reply, click, hold, join, launch, pair liquidity.
2. Name the lever you are pulling (social proof, identity, framing, cadence, small
   commitment, transparency, authority-by-proximity). One lever per piece.
3. Find the true, verifiable number or event that powers the lever. No number, no piece.

## While writing

- Lead with the number or the event, never with a claim about it.
- Make the crowd visible when it exists ("34 wallets bought in the first hour"). Never
  imply a crowd that is not there.
- State real windows plainly (tax decay clock, graduation lock). Never fabricate
  urgency, never "last chance", never countdowns that are not on-chain.
- Give the exact next step: the link, the contract, the command. One step.
- If the piece addresses a person (a Robinhood employee, a KOL, a community member),
  add information they do not have; flattery and volume are noise they filter.

## After writing (self-check)

- Would this still read as fair if the reader knew exactly why each word was chosen?
  If not, it is manipulation; cut it.
- Does it contain a return promise, a price target, a disclaimer or a sign-off? Cut it.
- Record the lever used in the rationale so the outcome study can grade levers.

## What Nudge does with the results

The behavioral analyst reads engagement and conversion readbacks per lever and reports
which levers moved which metric, so the swarm learns from evidence, not taste.
