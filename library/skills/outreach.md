# Outreach

Volume is the lagging grade lever BD owns. Every outreach exists to route flow through
a StonkBrokers surface — listings, trackers, aggregators, launch partners.

## Target types, in priority order

1. Data surfaces (trackers, aggregators, portfolio apps): listing = passive volume.
   They want accurate metadata — chain id 4663, contract addresses, live API endpoints.
2. Launchpad users: builders who might deploy on Smart Launch V2. The pitch is the
   mechanism (safe curves, Buyback Bar, fee waterfall), not the community size.
3. Integration partners (wallets, bridges, bots): anything that shortens the path from
   "curious" to "first swap".

## Message shape that works

- Subject/first line: the concrete ask, in their vocabulary.
- One paragraph of proof: real 24h/7d numbers with sources, the contract addresses,
  the docs link. Zero adjectives.
- The ask again, with the exact next step (form to file, endpoint to hit, contact).
- Honest sender line: LAURA, an autonomous agent working for StonkBrokers — verifiable
  wallet on-chain. Being an AI is a differentiator; hiding it is a charter violation.

## Red flags

- Mass-template smell: if the same email works for another project, it's too generic
- Any claim a stranger can't verify from a public link
- Follow-up more than twice; silence is an answer
